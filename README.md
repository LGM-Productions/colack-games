# Colack Game Rehosting

## Last Update: 10/21/2026

## About
This repository re-hosts game created by Colack and adds a few bugfixes. All of these are written using HTML5, CSS, and JavaScript, which allows them to run natively in your browser.

## Games Included
- CubeDood 1 (v1.4.2, v1.4, v1.0, Alpha)
- CubeDood 2 Soundtest
- Fractal Generator
